### 4.2 Scalar field

Per tissue piece, on a regular grid (start with 50 micrometre bins; fix the bin size and smoothing bandwidth on the development set):

- **Primary field: local stromal fraction** = smoothed count of stromal-proxy cells divided by smoothed count of all cells. It lies in [0, 1] and is independent of overall cell density by construction.
- **Negative-control field: total cell density.** This is what the alpha filtration saw. It is expected to add little.
- Build a tissue mask from cell density. Process each tissue piece separately and aggregate per slide by area-weighted mean.

### 4.3 Persistence and summary statistics

- Cubical persistence of the primary field with Cubical Ripser or GUDHI. Compute H1 of the superlevel sets of stromal fraction (rings of scar) and H0 of the sublevel sets (islands of parenchyma). In 2D these two are dual and should agree; report both as a consistency check.
- Record, for every persistence pair, the birth and death locations and whether the class touches the tissue-mask boundary. Report every statistic with and without boundary-touching classes.
- **Primary statistic (one, fixed in advance): total H1 persistence of the stromal-fraction field per square millimetre of tissue.**
- Secondary statistics: number of H1 classes per square millimetre above a persistence threshold fixed on the development set; distribution of enclosed nodule areas.
- For each persistent class, export the enclosed region (the parenchyma island at its death threshold). These regions are the candidate "highlighted structures" for the viewer.

### 4.4 Baselines the topology has to beat

Compute per slide: global stromal fraction, total cell density, cell-type composition vector, Moran's I of the stromal-fraction field (spatial clustering), the existing topocyte summary features, the Betti-curve fPCA scores, and a **fixed-threshold morphometry baseline** (number and size of parenchyma islands at one threshold of the stromal fraction, with no persistence).

### 4.5 Tests

All tests use the primary statistic first. Report effect sizes with bootstrap confidence intervals, not just p-values.

1. **Detection.** Nodular cirrhosis against matched controls: AUROC of the primary statistic alone, and of each baseline alone.
2. **Beyond composition.** Logistic regression of group on global stromal fraction, total density and Moran's I; then add the primary statistic. Report the change in cross-validated AUROC and the likelihood-ratio test.
3. **Label-shuffle null.** Within each slide, permute cell-type labels across cell positions (positions and global composition unchanged), recompute the field and statistic, 100 times. Report where the observed value falls in this null for each group.
4. **Phase-randomised null.** For each field, generate surrogates with the same power spectrum and randomised Fourier phases (same two-point statistics, different higher-order structure), 100 times. This is the stricter test: it asks whether the rings are more than spatial clustering at a given scale.
5. **Specificity.** Nodular cirrhosis against the non-nodular fibrosis contrast group, adjusted for global stromal fraction. Small sample; report as descriptive.
6. **Dose-response.** Trend of the primary statistic across stages 0 to 4 (Jonckheere-Terpstra or Spearman), raw and adjusted for global stromal fraction and Hardy scale.
7. **Persistence against fixed threshold.** Compare the primary statistic with the fixed-threshold morphometry baseline in tests 1 and 6, and under changes of bin size and smoothing (plus and minus 50%).
8. **Negative control.** Repeat tests 1 and 2 with the total-density field.

### 4.6 Visual check

For 10 nodular, 5 non-nodular fibrosis and 10 control slides, export the stromal-fraction field and the regions of the most persistent classes into the viewer (see section 6). Produce a contact sheet for the report. Simon inspects these before any go decision.

### 4.7 Go / no-go, fixed in advance

Phase 1 **passes** if all of the following hold on the primary statistic:

- Test 1: AUROC confidence interval excludes 0.5 and the point estimate is at least as high as the best single baseline.
- Test 2: adding the statistic improves cross-validated AUROC over the composition-and-clustering model, with the likelihood-ratio test significant at 0.01.
- Tests 3 and 4: in the nodular group, the observed statistic exceeds the 95th percentile of both nulls in a clear majority of slides, and does so far less often in controls.
- Test 6: monotone trend that survives adjustment.

If it fails, stop. Write up why: which test failed, whether the stromal proxy is adequate (H&E-derived cell types may not resolve scar well; one pathology note itself asks for a trichrome stain), and whether the tissue pieces are too small for the nodule sizes present. **A clear negative result is an acceptable outcome. ## 5. Phase 2 (conditional): Topological GNNs

Run only after Phase 1 passes and Simon approves.

### 5.1 What TOGL is

"Topological Graph Neural Networks", Horn, De Brouwer, Moor, Moreau, Rieck, Borgwardt, ICLR 2022, arXiv 2102.07835. Reference code: https://github.com/BorgwardtLab/TOGL (work in progress, Python 3.7/3.8).

A TOGL layer sits between two GNN layers. An MLP maps each node embedding to k scalars, each a learned vertex filtration (k = 8 in the paper). Edges take the max of their endpoints. Persistence is computed in dimensions 0 and 1; dimension 0 is a sort plus union-find. Each dimension-0 (birth, death) tuple belongs to one node and is added residually to its features. Gradients flow because each birth and death is the filtration value of one node. On a bare graph, dimension-1 classes never die, so they carry birth values only.

Project-specific design decisions:

- Use a **planar graph** so that rings appear as dimension-0 classes of the complement (a nodule is a component of non-scar tissue). Default for cells: Delaunay triangulation with long edges removed. Also build a **coarse grid graph** on the Phase 1 bins, which matches the millimetre scale of nodules and is far cheaper than a million-node cell graph. Compare the two.
- Add a tiny fixed per-node offset to each filtration so the vertex order is strict; log the fraction of tied values.
- Persistence on CPU (Numba or C++ union-find returning birth and death node indices), network on GPU. Unit-test persistence against GUDHI.
- If the reference repo's dependencies are too old, reimplement the layer in current PyTorch Geometric.

### 5.2 Question and design

The question is whether a **learned** filtration finds more than the fixed stromal-fraction filtration from Phase 1.

- **Primary task: ordinal fibrosis stage** (reviewed labels). Secondary: cirrhosis against matched controls. Exploratory only: age regression (75% of donors are aged 50 to 69, so the usable range is narrow) and the existing three-class disease label.
- **Primary comparison, fixed in advance:** one backbone (GIN), cell-level Delaunay graph with the existing topocyte cell features, with and without one TOGL layer. Everything else below is labelled exploratory.
- Exploratory: GCN and GAT backbones; tile graphs with foundation-model embeddings (reproduce Shreshta's GAT result first); k in {1, 4, 8}; layer placement; kNN and radius graphs.
- **Controls:** (a) same added capacity without persistence; (b) the Phase 1 statistic and baselines on the same splits; (c) TOGL initialised so that one filtration equals the stromal fraction.
- **Protocol:** donor-level repeated stratified k-fold with nested tuning, identical splits for all models, at least 3 seeds, paired differences with confidence intervals. Hardy scale as a covariate or stratification variable.
- **Stability:** for each slide, correlate the learned filtration maps across seeds and folds (after matching filtrations by best correlation). Report this; unstable maps cannot be used as figures.
- **Scale:** profile a full-slide forward and backward pass on the largest slide first. Prefer full slides with gradient accumulation; fall back to large spatial crops only if memory requires it, and report full-slide numbers.
